# WHATSZLINKCONVERTER (React + TypeScript + CSS puro)

Projeto reconstruído com React em TSX e CSS puro (sem Tailwind).

## Importante sobre erro de MIME
Se você abrir `index.html` direto ou usar um servidor estático sem build, scripts TSX podem falhar com erro de MIME.
Use sempre os comandos abaixo para rodar corretamente com o Vite (que transpila TSX para JS):

```bash
npm install
npm run dev
```

## Produção

```bash
npm run build
npm run preview
```
